# Matrizes e vetores em C

Exercício em C no arquivo `mat.c`: lê uma matriz 3×4, imprime a matriz, soma cada linha em um vetor de três posições e calcula a soma geral.

## Estrutura

- `mat.c`: programa único com matriz 3×4.
- Pastas `Lista_Exercicios/`, `Testes/` ou `output/`, quando presentes: organização dos códigos e artefatos.

## Como executar

Requisito: GCC configurado no terminal.

```bash
git clone https://github.com/Pedro-Bonelli/vetores-matrixzes_c.git
cd vetores-matrixzes_c
gcc mat.c -o programa
./programa
```

No PowerShell do Windows, execute `./programa.exe` (ou `.\programa.exe`). Cada arquivo `.c` é um exercício independente, salvo indicação no próprio código.

## Observações
